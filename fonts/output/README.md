# Generated Font Output

Holds the derivative font produced by the build pipeline.

After `make build`:
- Nayana-Regular.otf — generated font
- OFL.txt — SIL Open Font License 1.1 (ships with the OTF)

Obtain OFL.txt from https://scripts.sil.org/OFL or copy from Comic
Neue's repo. Place it here before `make package`.
