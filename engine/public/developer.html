Acid tests

Two end-to-end tests prove the encoding contract — both runnable from a clone of the repo.

Acid test 1 — codepoint correctness

The IPA inventory page itself is the test: every cell in the "Nayana" column shows the rendered glyph alongside the system-font rendering of the same codepoint. If the Nayana cell shows a fallback shape, that codepoint is missing from the font.

→ Open inventory

Acid test 2 — IPA → audio round-trip

Engine output is real IPA — provable by piping it through espeak-ng to synthesize speech. The validator script audits every character against the known IPA inventory, converts to X-SAMPA, and writes a playable .wav.

node engine/scripts/validate-ipa-encoding.js "..." --tts out.wav

Architecture

Engine

Node.js. CMUdict (~130k words) + Phonetisaurus alignment + position-based grapheme→phoneme rules. 18 phases, 538 unit tests. Pure JS — no Node-only deps in the rule modules, so it can be ported to client-side or serverless when needed.

→ AGENTS.md (handoff doc)

Font

OpenType (CFF). Source is a FontForge SFD file; build is a passthrough — every shape decision is locked in the SFD. Family name: Nayana English. Drawn over Comic Neue's Latin skeleton with custom IPA glyphs.

→ Codepoint reference

Deployment

Single multi-stage Docker image (~300 MB). Works on any container host: Fly.io, Railway, Render, DigitalOcean App Platform, plain VPS with Docker.

→ Deployment notes

Override mechanism

CMUdict has occasional wrong transcriptions. An overrides file (engine/data/cmudict-overrides.txt) patches them on a per-word basis without touching the upstream dictionary.

→ Current overrides

Design philosophy

Two principles the project commits to, recorded in AGENTS.md and enforced through every design decision:

  • IPA encoding is non-negotiable. Every phoneme naYana emits uses its canonical IPA Unicode codepoint — same one a phonetics textbook or a text-to-speech engine would consume. The font draws those codepoints with friendlier shapes, but the underlying text is standards-compliant IPA.
  • Script reflects pronunciation, not prescription. Different English varieties (Indian English, RP, Australian, GA) pronounce the same word differently and so will have different naYana spellings. There's no "correct" naYana spelling in the abstract — only the spelling that matches how a particular variety actually sounds.
